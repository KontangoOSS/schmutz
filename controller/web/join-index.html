Secure Network Enrollment

1 Welcome to Kontango

You're about to join the Kontango secure network platform. This script will:

  • Collect comprehensive device fingerprint data
  • Establish Ziti tunnel connectivity
  • Install the Kontango agent
  • Configure automatic health reporting

2 Data Collection

The installation script will collect detailed information about your system for device verification and secure enrollment. This includes:

  • System identification: hostname, serial number, machine UUID, boot ID
  • Operating system: version, kernel, architecture, timezone
  • Hardware: CPU model, cores, RAM, disk serials, BIOS version
  • Network: MAC addresses, DNS servers, gateway, open ports
  • Security: SSH host keys, device fingerprint hashes

All data is encrypted in transit (TLS/Ziti) and at rest (Bao).

3 Installation Steps

The installer will:

  • Display the User Agreement (acknowledge with Y)
  • Collect system fingerprint
  • Enroll with the controller via SSE stream
  • Download Ziti tunnel binary
  • Start Ziti tunnel service
  • Download Kontango agent
  • Configure systemd services for automatic startup
  • Send progress updates via Ziti-authenticated channel

4 Install Now

Copy and paste this command into your terminal:

curl -fsSL https://join.kontango.io/install | sh

With auto-approval (skip ULA prompt):

curl -fsSL https://join.kontango.io/install | sh -y
⚠ Important: Always review the User Agreement before installation. The ULA explains what data is collected and how it's used.

5 After Installation

  • Device enrolls with Ziti network overlay
  • SSH access available via Ziti (admin only)
  • Internal API accessible at {nickname}.tango:8080
  • Periodic health checks sent to controller
  • Real-time progress visible in controller dashboard

6 Troubleshooting

If the installation fails:

# View installation logs journalctl -u tango-tunnel.service -f journalctl -u tango-agent.service -f # Check Ziti tunnel status systemctl status tango-tunnel.service # Verify enrollment cat /opt/kontango/machine.json
