# Source Code

Place your application source code in this directory.

Structure according to your language's conventions:

- **Go**: `cmd/`, `internal/`, `pkg/`
- **TypeScript/Node**: framework-specific layout
- **Python**: package directory with `__init__.py`
- **Rust**: `src/main.rs` or `src/lib.rs`

Add a `Makefile` at the project root with `build` and `test` targets for CI integration.
